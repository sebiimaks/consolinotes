# 1. Introduction

Welcome to consolinotes, an independent fork of [FSNotes](https://github.com/glushchenko/fsnotes).

FSNotes was originally developed by Oleksandr Glushchenko and contributors. consolinotes is maintained separately; crediting their work does not imply their involvement in or endorsement of this fork.

Start with the [consolinotes documentation](https://github.com/sebiimaks/consolinotes#readme), or [report an issue with this fork](https://github.com/sebiimaks/consolinotes/issues).

The other notes in this Welcome folder introduce features inherited from FSNotes, including shortcuts, tags, Markdown preview, and Git versioning. Some screenshots show the original FSNotes interface.

See [[2. Links]] for documentation and project links.
